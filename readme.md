# Personal Finance Analysis

## 1. Project Overview
Personal Finance Analysis is a Python project that helps in understanding and analysing personal spending habits. It uses financial transaction data stored in CSV files and processes it with the help of Pandas. The project gives a clear idea of how money is spent in different categories and how actual expenses compare with the given budget.

## 2. Objective
The main aim of this project is to analyse financial data and make it easier to understand. Through this project, we aim to:
- Organise and clean the given transaction data.
- Calculate total income and expenses.
- Find out which categories have the highest spending.
- Compare the given budget with actual expenses.
- Save the processed data for further use.

## 3. Technologies Used
The following tools and technologies are used in this project:
- **Python:** Main programming language.
- **Pandas:** Used for reading, cleaning and analysing data.
- **Jupyter Notebook:** Used to write and execute the code.
- **CSV Files:** Used to store the financial and budget data.
- **Visual Studio Code:** Used as the development environment.
- **Git and GitHub:** Used for version control and project storage.

## 4. Dataset
This project uses two CSV files:

**personal_transactions.csv**

It contains transaction details such as:
- Date
- Description
- Amount
- Transaction Type
- Category
- Account Name

**Budget.csv**

It contains:
- Category
- Budget

The transaction dataset contains 806 records from 1 January 2018 to 30 September 2019. The budget dataset includes 19 different categories.

## 5. How to Run
Follow these steps to run the project:

1. Install Python on your system.
2. Install Pandas and ipykernel using:
   `pip install pandas ipykernel`
3. Open the project folder in Visual Studio Code.
4. Open the `personal_finance_analysis.ipynb` notebook.
5. Select the Python kernel.
6. Run all the cells one by one or use Run All.
7. The cleaned transaction data and budget comparison will be saved as CSV files.
